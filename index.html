luach · לוח

A household calendar you can talk to.

Say “dentist next Tuesday at three”, by typing or with the mic, and luach puts it on the family calendar. Ask “is Saturday free?” and it answers from the calendar. Every change the assistant proposes passes a gate written in code: a guessed time, a likely duplicate or a change to someone else’s event waits for a person to say yes, and every decision is kept on an audit trail.

luach is free, open-source software that each family runs on its own server. There is no hosted service: the calendar, the conversations and the audit trail stay on a machine the family controls.

Get it

The server. The source, a quick start and the self-hosting guide are on GitHub.

The iPhone app. Install it and enter your luach’s address on the sign-in screen. It works with any household’s luach.

Support

Questions and problems: open an issue. Security reports go privately through the repository’s Security tab. For help with a particular household’s luach, ask whoever runs it.

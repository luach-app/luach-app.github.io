Careful by design

A calendar is a family’s shared memory. luach treats it that way.

  • A gate, written in code.Every change the assistant proposes passes rules in the program, not a sentence in a prompt. Inviting anyone outside the family always needs a tap.
  • Text from outside can’t give orders.Emails, web pages and booking notes reach the assistant as data, never as instructions.
  • An audit trail.Every decision is kept on a tamper-evident record. Each member sees their own.
  • Private by default.Each person’s conversations are theirs alone. Your family’s data stays on your server; nothing goes to us.
  • Your model, your choice.Run one at home so nothing leaves the house, or pick a cloud model. The app asks before using one.

Run your own luach

luach isn’t a service you sign up for. Each family runs its own, on a computer it controls. If you can follow a recipe, you can do this in an afternoon.

What you need

  • A computer that stays on.A small home server or mini PC, a NAS that runs Docker, or a small cloud server. 2 GB of memory is plenty.
  • A web address.A domain name for your luach, so phones and browsers can reach it securely over https.
  • An AI model.A cloud API key (a family typically spends a few dollars a month), or a model running at home on a machine with a good GPU.
  • Optional:a Google Calendar to sync with, Gmail import, outgoing email, voice, web search.

The steps

  1. Install Docker on that computer.
  2. Get luach and copy its settings file: 
    git clone https://github.com/luach-app/luach.git
cd luach && cp .env.example .env
  3. Choose a model. Put its address, key and name in .env: a cloud provider such as OpenRouter, or Ollama on your own machine.
  4. Start it and read the one-time setup code from its log: 
    docker compose up -d
docker compose logs luach | grep -A3 "setup code"
  5. Give it a web address with https. The guide includes a ready-made setup with Caddy, which gets the certificate for you.
  6. Create the household. Open your address, enter the setup code, then invite the family by email. Install the iPhone app and type your address.

The full guide walks through every step and every optional extra, with the exact settings, backups, upgrades and troubleshooting. The source is on GitHub.

Questions

Is there a version I can just sign up for?

No, on purpose. luach holds a family’s plans, conversations and, if you connect it, email. It belongs on a computer the family controls. Nobody, including us, runs one for you.

Does my family’s data go anywhere?

Your calendar, conversations and memory stay on your server. What you ask goes to the AI model you configured: if it runs at home, nothing leaves the house; if it’s a cloud model, that provider sees the request. The app shows which, and asks first.

Do I need Google?

No. luach keeps its own calendar. If your family already lives in Google Calendar, it can use that instead, and Gmail import is optional.

What does it cost?

luach is free. You pay for your own computer or cloud server, a domain, and, if you use one, a cloud AI model, typically a few dollars a month for a family.

Android?

The web app works on any phone and can be added to the home screen. A native Android app isn’t planned yet.
